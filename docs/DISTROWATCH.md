# DistroWatch: a possible future milestone

Skaldr OS exists first and foremost as a **personal, public Linux project**.
Being listed on DistroWatch is neither an obligation nor the goal of development.

A realistic path, **if it becomes worthwhile**, is:

- Publish one genuinely successful, installable and independently checked ISO.
- Provide a stable version number, clear release notes and SHA-256 checksums.
- Document how Skaldr differs from its parent CachyOS, without implying endorsement.
- Keep download links available and show authentic desktop and installer screenshots.
- Explain minimum hardware requirements, support expectations and known limitations.
- Maintain a consistent sequence of updates and take time to address real bug reports.
- Only then evaluate the current DistroWatch submission instructions:
  https://distrowatch.com/dwres.php?resource=submit

**No submission has been made and no listing is promised.**
Community usefulness and reliable releases matter more than publicity.
